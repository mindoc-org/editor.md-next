# 多语言（i18n）

## 内置语言

`zh-cn`（默认）、`en`、`zh-tw`。

```ts
new EditorMD('#editor', { i18n: 'en' })
```

覆盖范围：工具栏提示、对话框文案、目录标题、CM6 搜索面板短语。

## 运行时切换

语言参与编辑器构建，切换需重建实例：

```ts
editor.config({ i18n: 'en' })
```

## 自定义语言包

```ts
import { EditorMD, registerLang } from 'editor.md-next'
import type { LangDict } from 'editor.md-next'

const ja: LangDict = {
  name: 'ja',
  description: '…',
  tocTitle: '目次',
  toolbar: { bold: '太字（Ctrl-B）/* 其余按键同理 */' },
  search: { Find: '検索' /* CM6 搜索面板短语 */ },
  buttons: { enter: 'OK', cancel: 'キャンセル', close: '閉じる' },
  dialog: {
    link: { title: 'リンク追加', url: 'URL', urlTitle: 'タイトル', urlEmpty: '…' },
    referenceLink: { /* … */ },
    image: { /* … */ },
    codeBlock: { /* … */ },
    preformattedText: { /* … */ },
    table: { /* … */ },
    emoji: { /* … */ },
    htmlEntities: { title: '…' },
    gotoLine: { /* … */ },
    help: { title: '…' },
    info: { /* … */ },
  },
}
registerLang(ja)

new EditorMD('#editor', { i18n: 'ja' })
```

`LangDict` 完整类型见包内导出的 `LangDict`（`*.d.ts`）。未提供的键回退到 zh-cn。
