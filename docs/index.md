# editor.md-next 文档

editor.md-next 是 [editor.md](https://github.com/pandao/editor.md) 的 TypeScript 重写版：基于 **CodeMirror 6** 与 **markdown-it** 的现代 Markdown 编辑器，无 jQuery 依赖。

## 文档目录

| 文档 | 内容 |
| --- | --- |
| [getting-started.md](getting-started.md) | 安装（npm / CDN）与快速上手 |
| [configuration.md](configuration.md) | 全部配置项说明 |
| [api.md](api.md) | 实例方法与事件 |
| [markdown-extensions.md](markdown-extensions.md) | 扩展语法（TOC/emoji/公式/图表/分页…） |
| [vue3.md](vue3.md) | Vue 3 组件适配（editor.md-next-vue） |
| [react.md](react.md) | React 组件适配（editor.md-next-react） |

| [offline.md](offline.md) | 离线/内网部署（CDN 自托管） |
| [themes.md](themes.md) | 主题与自定义 |
